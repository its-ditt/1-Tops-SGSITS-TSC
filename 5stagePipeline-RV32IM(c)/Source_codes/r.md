Processor is still being debugged.



To use the processor import all modules in VIVADO or copy paste them into a folder. 
For Simulation:-
Create a "program.hex" file in simulation folder (xsim folder for VIVADO)
Write your instructions in 8 hexadigits per line format with no "0x" prefix eg-

    04089ca6
    200c56d3

Using suitable testbench, run the simulation.
